# תכנון החתונה שלי — Wedding Planner

אפליקציית React בעברית ובכיווניות RTL לניהול מוזמנים, הושבה, ספקים, משימות ותקציב. נתוני ענן נשמרים ב-Firebase; אפשר גם להפעיל את האפליקציה במצב מקומי ללא חיבור לחשבון Firebase.

## הפעלה מקומית

דרישות: Node.js 22 ומעלה ו-npm.

```powershell
npm install
Copy-Item .env.example .env
npm run dev
```

כדי להשתמש בסנכרון ענן, מלאו ב-`.env` את הגדרות אפליקציית ה-Web של Firebase לפי `.env.example`, והשאירו `VITE_FIREBASE_ENV=test` במהלך פיתוח. כדי לבדוק את הממשק בלבד, אפשר להשאיר את הגדרות Firebase ריקות ולהשתמש במצב המקומי.

## ארכיטקטורה

- **React 19 ו-Vite 8** מציגים את האפליקציה; Tailwind CSS 4 מספק את העיצוב.
- **Firebase Authentication** מנהל התחברות, אימות כתובת ואיפוס סיסמה.
- **Cloud Firestore** שומר חתונות, חברים, מוזמנים, שולחנות, ספקים, תקציב, משימות והגדרות.
- **Firebase Storage** שומר קבצים מצורפים לספקים ותמונת רקע לספירה לאחור.
- **Cloud Functions** מטפלות בפעולות שדורשות הרשאות שרת, ובהן הזמנות, ניהול חברים ומפתחות גישה.
- **localStorage** משמש מטמון ומצב עבודה מקומי. במצב ענן הנתונים מופרדים לפי משתמש וחתונה.

קוד הלקוח נמצא ב-`src/`, פונקציות הענן ב-`functions/`, וכללי הגישה נמצאים ב-`firestore.rules` וב-`storage.rules`. קובץ `firebase.json` מגדיר את פריסת הכללים והפונקציות; הוא אינו מגדיר שירות Hosting לאתר.

## סודות והרשאות

ערכי `VITE_FIREBASE_*` הם הגדרות לקוח פומביות ונכללים בקובצי האתר. הרשאות הנתונים נאכפות בכללי Firestore ו-Storage ובבדיקות ההרשאה של הפונקציות. לעולם אל תכניסו מפתח שירות או סוד אחר למשתנה `VITE_*`. `FIREBASE_SERVICE_ACCOUNT` מיועד לסקריפטים מקומיים בעלי הרשאות ניהול, ויש לשמור את הקובץ הפרטי מחוץ ל-Git.

הפרדה בין `VITE_FIREBASE_ENV=test` ל-`prod` בוחרת מרחב נתונים באותו פרויקט; היא אינה תחליף לפרויקטי Firebase נפרדים או לאמולטורים כשנדרשת הפרדה מלאה.

## בדיקות ובנייה

```bash
npm run build
npm run lint
npm run test:excel
npm run test:import
npm run test:backup
npm run test:guide
```

בדיקות מקצה לקצה משתמשות באמולטורים של Firebase:

```bash
npm run test:e2e
```

התקנת הדפדפנים ל-Playwright, אם נדרשת:

```bash
npm run e2e:install-browsers
```

## פריסה

`npm run build` יוצר את האתר הסטטי ב-`dist/`. יש להגדיר את משתני Firebase בסביבת הבנייה ולפרוס את `dist/` בשירות אירוח סטטי מתאים. קובץ `public/_headers` מכיל כותרות אבטחה למארחים שתומכים בפורמט זה. כללי Firestore, כללי Storage ופונקציות הענן מנוהלים בנפרד דרך Firebase CLI.

## גיבוי

האפליקציה תומכת בגיבוי JSON ובייצוא XLSX. ניתן להצפין את קובץ הגיבוי בסיסמה; סיסמה שאבדה אינה ניתנת לשחזור. קובצי ספקים המאוחסנים ב-Storage אינם מוטמעים בגיבוי הנתונים.
